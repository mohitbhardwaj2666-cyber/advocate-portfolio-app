# Advocate Portfolio App

A React + Vite portfolio application for Advocate V. Sharma with Firebase auth and Firestore integration.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Notes

- Set `__firebase_config` and `__initial_auth_token` in your hosting environment if required.
- This project uses Tailwind CSS and Firebase.
